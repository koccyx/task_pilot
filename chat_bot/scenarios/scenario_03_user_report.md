# Сценарий: Отчёт по карточкам пользователя

**Триггер**: "сделай отчёт за месяц", "мои задачи за неделю"

**Шаги**:
1. Определить user_name и период (неделя=-7д, месяц=-30д)
2. `manage_users(action="list")` → найти user_id
3. `manage_cards(action="list", owner_id=..., condition=2)` — завершённые
4. `manage_cards(action="list", owner_id=..., condition=1)` — активные
5. Для каждой: `manage_comments(action="show", card_id=...)`
6. Сформировать отчёт:
```
📊 Отчёт: Имя (период)
## Выполнено (N): задача1, задача2...
## В работе (M): задача3...
```
