# Сценарий: Настройка доски с колонками и задачами

**Триггер**: "создай доску", "настрой доску", "сделай доску с колонками и задачами"

**Пример запроса**:
"Создай доску Питчинг в пространстве Тимур, добавь колонки Очередь, Выполняется, Готово, и создай 5 задач с ответственным Тимур"

**Шаги (выполняются последовательно в одном ответе)**:

1. `manage_boards(action="create", space="...", title="...")` → получить board_id
2. Для каждой колонки:
   - `manage_columns(action="create", board_id=..., title="...")` → получить column_id первой колонки
3. Для каждой задачи:
   - `manage_cards(action="create", board_id=..., column_id=..., title="...")` → получить card_id
   - `manage_members(action="set_responsible", card_id=..., owner_name="...")`

**Важно**:
- Все шаги выполняются за ОДИН ответ бота
- Каждый вызов с разными параметрами — это РАЗРЕШЕНО
- Не спрашивать подтверждение на каждый шаг

**Финальный отчёт**:
```
✅ Готово!
📋 Доска: «Питчинг» (ID: 123)
📊 Колонки: Очередь, Выполняется, Готово
📝 Создано задач: 5
👤 Ответственный: Тимур
```
